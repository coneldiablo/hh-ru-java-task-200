# Решение задачи hh.ru на Java

Между цифрами `9876543210` нужно поставить `+`, `-` или оставить промежуток пустым,
чтобы получить выражение со значением `200`. Порядок цифр сохраняется, каждая цифра
используется один раз. Программа выводит все подходящие выражения.

Решение находится в [Main.java](Main.java). Внешние библиотеки не нужны.

## Как запустить

Нужен JDK 8 или новее. Команды `java` и `javac` должны быть доступны в терминале.
Проверить установку можно командами `java -version` и `javac -version`.

```bash
git clone https://github.com/coneldiablo/hh-ru-java-task-200.git
cd hh-ru-java-task-200
javac -encoding UTF-8 Main.java
java Main
```

Вводить данные не нужно: последовательность цифр и целевое значение заданы
константами `DIGITS` и `TARGET`.

## Результат

```text
98+76-5+43-2-10=200
98-7+65+43+2-1+0=200
98-7+65+43+2-1-0=200
9-8+7-6-5-4-3+210=200
9-8-7-6-5+4+3+210=200
```

Варианты с `+0` и `-0` выводятся отдельно: это разные расстановки знаков.

## Как работает решение

Используется рекурсивный полный перебор. Для каждой следующей цифры есть три варианта:

1. Присоединить её к текущему числу: `number * 10 + digit`.
2. Поставить `+`: добавить текущее число с его знаком к сумме и начать новое положительное число.
3. Поставить `-`: добавить текущее число с его знаком к сумме и начать новое отрицательное число.

`sum` хранит сумму уже завершённых чисел, `number` — текущее число, а `sign` — его
знак. Когда все цифры обработаны, проверяется `sum + sign * number == TARGET`.
Если равенство выполняется, выражение выводится.

Между десятью цифрами девять промежутков, поэтому перебирается `3^9 = 19 683`
варианта. Все вычисления выполняются в типе `long`, который вмещает числа,
получающиеся из этой последовательности.
